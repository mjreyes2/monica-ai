## 🎮 COMPLETE CONTROLS

### Camera Selection
| Control | Function |
|---------|----------|
| **X key** | Toggle camera selection on/off |
| **Click button** | Open camera selection |
| **Click camera** | Switch to that camera |
| **ESC** | Close camera selection |

### Other Controls
| Key | Function |
|-----|----------|
| **F** | Fullscreen |
| **M** | Maximize |
| **H** | Toggle hand skeleton |
| **D** | Toggle debug boxes |
| **C** | Show settings |
| **ESC** | Quit (when not in camera selection) |
