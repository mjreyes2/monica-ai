**Solution**:
```bash
# Install Ollama
# Download from https://ollama.com
ollama pull llama3.2

# OR set Groq API key (free)
setx GROQ_API_KEY "your_groq_key"
```

### Issue: "Monica not speaking"
**Solution**:
```bash
pip install pyttsx3 gtts pygame
# Check system volume
# Verify speakers are working
```

### Issue: "Hand gestures not working"
**Solution**:
```bash
pip install mediapipe
# Check webcam is connected
# Ensure good lighting
```

### Issue: "YouTube download fails"
**Solution**:
```bash
pip install --upgrade pytube
# If still fails, use local video files instead
```

### Issue: "Web research not working"
**Solution**:
```bash
pip install --upgrade duckduckgo_search beautifulsoup4 lxml requests
# Check internet connection
```

### Issue: "Database error"
**Solution**:
```bash
# Delete and recreate database
del data\monica_memory.db
# Monica will recreate on next launch
```
