## ❓ TROUBLESHOOTING

### Monica won't start
**Run verification**:
```bash
python VERIFY_MONICA_COMPLETE.py
```

**Check dependencies**:
```bash
LAUNCH_MONICA.bat
# Choose option [0] Setup / Install Dependencies
```

### "Ollama not found"
**Install Ollama**:
1. Download: https://ollama.com
2. Install
3. Run: `ollama pull llama3.2`
4. Test: `ollama run llama3.2 "Hello"`

### No sound effects
- Check system volume
- Sounds are procedurally generated (no files needed)
- Should work automatically via pygame

### Globe is slow
- Normal on first run (building cache)
- Consider adding Groq API for faster AI responses
- Reduce zoom level if needed

### No webcams showing
- Many locations don't have public webcams
- Try major cities: "Show me webcams in Times Square"
- Add Windy API key for more sources

### Import errors
**Reinstall packages**:
```bash
pip install --upgrade ollama opencv-python numpy pandas pygame
pip install --upgrade openpyxl geopy beautifulsoup4 lxml requests
```
